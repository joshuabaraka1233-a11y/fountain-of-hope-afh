FOUNTAIN OF HOPE — WEBSITE STARTER

This is a responsive static website built with HTML, CSS and vanilla JavaScript.

TO PREVIEW
1. Extract the project folder.
2. Open index.html in a modern browser.

TO EDIT
- index.html: page content and sections
- styles.css: colours, layout, typography and responsive styling
- script.js: mobile navigation and photo gallery viewer
- assets/: supplied property photographs

IMPORTANT BEFORE PUBLIC LAUNCH
- Confirm the organisation's exact care services, location, contact details and operating information.
- The phone number and street address supplied by the owner are included. The enquiry action currently uses a tap-to-call link; no email address was supplied.
- Confirm permissions to publish all property photographs.
- Review all care-related wording to ensure it accurately describes the services actually provided.

No ratings or reviews page is included.
